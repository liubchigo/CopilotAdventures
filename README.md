# Copilot Adventures

Welcome! Copilot Adventures is a friendly collection of fantasy-themed coding challenges that help you learn with [GitHub Copilot](https://github.com/features/copilot).

## Start your adventure

1. [Open a Codespace](https://codespaces.new/microsoft/CopilotAdventures)  
   or clone locally:
   ```bash
   git clone https://github.com/microsoft/CopilotAdventures
   ```
2. Pick a path:
   - [Agent adventures](./Adventures/Agent/)
   - [Ask adventures](./Adventures/Ask/)
3. Build your solution in your favorite language from the [Solutions](./Solutions/) examples.

## Copilot modes

- **Agent Mode**: great for autonomous, end-to-end building.
- **Edit Mode**: ideal for fast multi-file updates.
- **Ask Mode**: perfect for step-by-step learning.

## Share your work

Have a solution to share? Please open an issue.  
Have a brand-new adventure to contribute? Please submit a PR with:
`New Copilot Adventure: [Your Adventure Name]`.
