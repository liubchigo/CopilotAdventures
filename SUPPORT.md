# Support

Thanks for using Copilot Adventures! We’re happy to help.

## How to file issues and get help

We use GitHub Issues for bugs, ideas, and questions:
- Search existing issues first to avoid duplicates.
- Open a new issue with clear steps, expected behavior, and what you observed.
- Add screenshots or logs when helpful.

For general help and discussion:
- Join the [Azure AI Foundry Discord](https://aka.ms/foundry/discord)
- Visit the [Azure AI Foundry Developer Forum](https://aka.ms/foundry/forum)

## Microsoft support policy

Support for this project is limited to the community resources listed above.
