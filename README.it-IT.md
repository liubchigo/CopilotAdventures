# Copilot Adventures

Benvenuto! Copilot Adventures è una raccolta di sfide fantasy per imparare a programmare con [GitHub Copilot](https://github.com/features/copilot) in modo pratico e divertente.

## Inizia subito

1. Apri un Codespace: https://codespaces.new/microsoft/CopilotAdventures  
   oppure clona in locale:
   ```bash
   git clone https://github.com/microsoft/copilotadventures
   ```
2. Scegli il tuo percorso:
   - [Avventure Agent](./Adventures/Agent/)
   - [Avventure Ask](./Adventures/Ask/)
3. Usa gli esempi nella cartella [Solutions](./Solutions/) per iniziare.

## Modalità Copilot

- **Agent Mode**: perfetta per creare soluzioni complete in autonomia.
- **Edit Mode**: ottima per modifiche rapide su più file.
- **Ask Mode**: ideale per imparare passo dopo passo.

## Condividi la tua avventura

Vuoi contribuire? Fantastico! Apri una issue o una PR con il titolo:
`Nuova Avventura Copilot: [Nome della tua Avventura]`.

Se ti serve aiuto, unisciti alla [Azure AI Foundry Discord](https://aka.ms/foundry/discord) o visita il [Developer Forum](https://aka.ms/foundry/forum).
