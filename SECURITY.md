Thanks for helping keep Copilot Adventures secure.

## Report a security issue

Please **do not** report vulnerabilities in public GitHub issues.

Instead, report privately to the Microsoft Security Response Center (MSRC):
- Web: https://aka.ms/security.md/msrc/create-report
- Email: [secure@microsoft.com](mailto:secure@microsoft.com)

If possible, include:
- issue type and impact
- affected file paths and branch/commit
- steps to reproduce
- proof-of-concept details

You should receive a response within 24 hours.

For more information, see [microsoft.com/msrc](https://www.microsoft.com/msrc) and Microsoft’s [Coordinated Vulnerability Disclosure policy](https://aka.ms/security.md/cvd).
